# Crypto Tracker 99

Crypto Tracker 99 is a Python-based application designed to simplify cryptocurrency management and analysis. It provides real-time price updates, market trends, and portfolio tracking, empowering users to make informed investment decisions.

## Features
- **Real-Time Price Tracking:** Get live updates on the latest cryptocurrency prices from major exchanges.
- **Portfolio Management:** Manage your crypto assets and track gains or losses over time.
- **Market Trends Analysis:** Analyze market trends with interactive charts and historical data comparisons.
- **Alerts and Notifications:** Set price alerts to never miss a significant market movement.

## Installation

To get started with Crypto Tracker 99, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/Developer/crypto-tracker-99.git
   ```

2. Change to the project directory:
   ```bash
   cd crypto-tracker-99
   ```

3. Create a virtual environment (optional but recommended):
   ```bash
   python3 -m venv venv
   source venv/bin/activate  # On Windows use `venv\Scripts\activate`
   ```

4. Install the required packages:
   ```bash
   pip install -r requirements.txt
   ```

## Basic Usage Example

After installation, you can start the application by running:

```bash
python main.py
```

To track a specific cryptocurrency, simply enter the symbol when prompted (e.g., `BTC` for Bitcoin, `ETH` for Ethereum). The application will provide you with real-time price updates and allow you to manage your portfolio seamlessly.
